# Nirmal Consultant

A premium corporate WordPress theme for financial services in Kathmandu Valley. Covers tax, accounting, financial modelling, business setup, payroll, corporate finance, investment advisory and risk management. Includes a conversion-focused homepage, 12 service pages, contact form, Customizer contact settings and automatic page creation on activation.

- **Version:** 2.0.0
- **Author:** Nirmal Kumar Bhattarai
- **License:** MIT

## Install

1. Download or clone this repository.
2. Copy the folder into `wp-content/themes/` on your WordPress site.
3. Activate it in WordPress admin (Appearance > Themes).
