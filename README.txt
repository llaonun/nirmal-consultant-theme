=== Nirmal Consultant v2.0.0 ===
A premium WordPress theme for Nirmal Bhattarai, Financial Consultant — Kathmandu Valley, Nepal.

QUICK INSTALL
1. In wp-admin go to Appearance → Themes → Add New → Upload Theme.
2. Upload nirmal-consultant.zip and click Install Now, then Activate.
3. On activation the theme automatically creates: Home, About, Services (+12 service
   pages), Industries, Contact, Privacy Policy and Terms of Service — plus a primary
   menu linking them. The homepage is set to the "Home" page automatically.

AFTER ACTIVATION
- Appearance → Customize → Contact Information: phone, email, address, hours.
- Appearance → Customize → Homepage Stats: edit the four stat numbers/labels.
- Appearance → Menus: the Primary menu is pre-built; adjust freely. The last item
  can use the CSS class "menu-cta" for the gold button style.
- Appearance → Widgets: three footer columns are available.
- The contact form ([nb_contact_form] shortcode) emails submissions to the address
  in Customize → Contact Information. Make sure your WordPress can send mail
  (most hosts support wp_mail; otherwise install an SMTP plugin).

WHAT'S INCLUDED
- 12 service pages, each with detail content and prev/next service navigation
- Conversion homepage: hero, stats, services grid, about, process, industries,
  insights, CTA band and contact section
- Working contact form (no plugin needed) with spam-safe nonce + validation
